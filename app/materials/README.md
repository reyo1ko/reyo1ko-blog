# 画像素材ページ

- URL: /materials
- 定義・共通プロンプト・配色: materials.ts
- 一覧と折りたたみUI: MaterialGallery.tsx
- ダウンロード先: public/materials/pixel-hardware/
- 元画像: assets/materials/source/
- 元画像と生成時プロンプトの対応: assets/materials/sources.json
- 一括書き出し: npm run materials:export

## 共通方針

ベンダー、製品、OSの種類を特定する意匠を使わない。画像は1台の機器、1つの仮想マシン、または1つのOSだけを示す。クラスター、複数台構成、接続線、分岐矢印は利用者が構成図に描く。

仮想化ホストは単体の物理サーバー。仮想マシンと物理OSは汎用的な別素材とし、SANは少数の大きいベイでアレイを表す。FCポートの形状はmaterials.tsの参考資料リンクを参照。

## 素材を追加・修正する

1. 共通テンプレートから対象の再現用プロンプトを作り、画像生成ツールで透過画像を生成する。
2. 元画像をassets/materials/source/{id}.pngへ保存する。
3. sources.jsonへID、元画像のパス、実際に使用した生成プロンプトを記録する。参考画像を使った場合は資料のURLも記録する。
4. MATERIALSへ名称、カテゴリ、説明、代替テキスト、512px版と1024px版のURL、再現用プロンプトを追加する。
5. インフラセットに含める場合はINFRASTRUCTURE_IDSへIDを追加する。
6. npm run materials:exportでPNG・プロンプトTXT・ZIPを更新する。

## 書き出しの注意

元画像のアルファを見て対象の境界を取得し、縦横比を保ったまま512px・1024pxのキャンバスへそれぞれ直接書き出す。四辺にキャンバスの1/16以上の透明な余白を確保する。64pxを経由した縮小や、その後の拡大は行わない。

色は共通5色に統一する。PNGの圧縮は可逆で、画質を落とす非可逆圧縮ではない。輪郭の細い半透明部分を過度に除去せず、孤立した1pxのアルファ欠けだけを補修する。元画像は再書き出しのため必ず保持する。

再現用プロンプトは同じテイストでの生成を目的とし、同一画像の完全再現を保証しない。実際の生成時プロンプトはsources.jsonに保存し、元画像との対応を残す。

SFPとLCデュプレックス光ケーブルを追加。SFPのみは細長い筐体と光ポートの両方を示す浅い斜め方向の構図とし、個別プロンプトに明記する。どちらも接続先や構成図を含めない単体素材。
